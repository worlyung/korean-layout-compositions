# 목차

**278종**의 구성 원리. 분류를 눌러 들어간다.

### [구도 논리 · 86종](01-composition-logic.md)
화면 안에서 요소를 어디에 놓고 어떻게 이어 볼 것인가. 매체를 가리지 않는 기본 골격.

### [시각 원칙 · 45종](02-visual-principles.md)
요소를 어떻게 묶고 나누고 강조할 것인가. 구도가 자리라면 원칙은 관계다.

<sub>균형 · 동세 · 초점(8) · 위계 · 비례 · 대비(12) · 반복 · 패턴 · 리듬(8) · 게슈탈트와 묶기(12) · 지면 읽기 패턴(5)</sub>

### [출판 · 광고 · 36종](03-editorial-advertising.md)
지면을 어떻게 나누고 무엇을 앞세울 것인가. 포스터·리플렛·도록의 판면 짜기.

<sub>단 · 펼침 · 재단(8) · 주도 요소와 표현형 판면(13) · 모듈 · 곁단 · 도판 관계(7) · 출판 기능 지면(8)</sub>

### [글자 · 격자 · 55종](04-type-grid.md)
글자를 어떻게 세우고 지면을 어떤 눈금으로 나눌 것인가. 마지막 절은 한글 조판 고유의 문제를 다룬다.

<sub>글자 조직 체계(8) · 정렬과 글자 조형(18) · 격자 체계(18) · 한글 조판(11)</sub>

### [영상 화면 · 14종](06-film-frame.md)
카메라가 인물과 공간을 어떻게 잡는가. 콘티와 촬영 계획에 쓰는 화면 어휘.

<sub>인물 수와 무리(4) · 시점과 커버리지(5) · 장면 배치와 깊이(5)</sub>

### [한국 전통 구도 · 26종](07-korean-tradition.md)

<sub>시점과 공간(6) · 격자와 진열(5) · 여백과 운필(9) · 상징과 배열(6)</sub>

### [발표 자료 · 16종](08-presentation.md)
